Enable Timeline Colors

For color changes to appear on timeline clips, enable this one-time setting in Premiere Pro:

1 Click the ⚙ Wrench icon in the Timeline panel (top-left corner)
2 Enable "Show Source Clip Name and Label"
3 Now click a color in this panel — all selected clips will update instantly

This setting links each timeline clip's color to its source project item. The panel changes the source item color via script, which Premiere then mirrors on the timeline.
